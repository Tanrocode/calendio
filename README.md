# Calendio

A full-stack, agentic AI scheduling SaaS platform.

## Monorepo Structure

- `/frontend` — React + Vite + TypeScript + Tailwind CSS
- `/backend` — FastAPI, SQLAlchemy, LangChain, PostgreSQL
- `docker-compose.yml` — Dev/prod orchestration

## Features
- Multi-tenant scheduling
- AI agent for intent extraction & appointment booking
- Modular, extensible architecture
